# FinTech Loan Analytics Dashboard

## 📌 Project Overview

An interactive Power BI analytics project designed to analyze loan applications, customer activity, approvals, and disbursement performance.

The project focuses on converting loan and customer data into business insights through KPI analysis, interactive dashboards, and visual reporting.

## 🎯 Business Objectives

- Monitor overall loan application and disbursement performance
- Analyze application and approval trends
- Understand customer and loan characteristics
- Identify performance patterns across business dimensions
- Provide an interactive dashboard for business decision-making

## 🛠️ Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Business Intelligence

## 📊 Analysis Areas

- Loan Applications
- Loan Approvals
- Loan Disbursements
- Customer Analysis
- Performance KPIs
- Trend Analysis
- Business Segmentation

## 📈 Dashboard

The Power BI dashboard provides an interactive view of key loan and customer performance metrics.

Users can explore the analysis using filters and visual interactions to identify trends and business performance patterns.

## 💡 Key Skills Demonstrated

- Data cleaning and transformation
- KPI development
- DAX-based calculations
- Interactive dashboard development
- Business performance analysis
- Data visualization
- Insight generation
