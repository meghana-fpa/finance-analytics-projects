# Retail Sales SQL Analytics

## 📌 Project Overview

A SQL analytics project focused on analyzing **customer purchasing behavior, completed orders, revenue contribution, and average order value**.

The analysis uses customer, order, and order-item data to identify customers with multiple completed orders and higher revenue contribution.

---

## 🎯 Business Objectives

- Analyze completed customer orders
- Measure customer purchase frequency
- Calculate total revenue generated by customers
- Calculate average order value
- Identify higher-value customers
- Understand customer revenue contribution
- Support customer and sales performance analysis using SQL

## 📊 SQL Analysis

The analysis combines data from three tables:

- `customers`
- `orders`
- `order_items`

The SQL query:

1. Joins customers with their orders and order items.
2. Filters the analysis to **Completed** orders.
3. Calculates the number of completed orders for each customer.
4. Calculates total customer revenue using quantity and unit price.
5. Calculates average order value.
6. Filters customers with more than one completed order.
7. Filters customers with total revenue of at least **10,000**.
8. Orders the final results by total revenue in descending order.

---

## 🔍 Key Metrics

The analysis calculates:

| Metric | Description |
|---|---|
| **Completed Orders** | Number of distinct completed orders for each customer |
| **Total Revenue** | Total revenue generated from completed orders |
| **Average Order Value** | Total revenue divided by completed orders |
