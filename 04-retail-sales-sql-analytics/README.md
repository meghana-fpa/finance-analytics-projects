# Retail Sales SQL Analytics

## 📌 Project Overview

A SQL analytics project focused on analyzing customer purchasing behavior, completed orders, revenue, and average order value.

## 🛠️ Tools & Technologies

- SQL
- Relational Database Analysis
- Data Aggregation
- JOIN Operations
- CTEs
- Business Metrics

## 📊 Analysis

The SQL analysis:

- Identifies completed customer orders
- Calculates completed order counts
- Calculates total customer revenue
- Calculates average order value
- Filters customers based on order activity and revenue
- Sorts customers by revenue contribution

## 🎯 Business Objective

The analysis helps identify high-value customers based on completed order activity and revenue contribution.
